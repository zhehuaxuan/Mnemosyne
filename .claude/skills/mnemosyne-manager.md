# Mnemosyne 知识库管理 Skill

这个 Skill 帮助管理 Mnemosyne Obsidian 知识库，包括：
- 遵循 PARA + Zettelkasten 方法论组织笔记
- 维护笔记间的双向链接
- 支持 AI 辅助的知识提取和整理

## 使用方法

当用户询问关于知识库操作时，使用以下原则：

### PARA 分类指南

| 分类 | 说明 | 示例 |
|------|------|------|
| Projects | 有明确目标和截止日期的 | AI Agent 研究、项目文档 |
| Areas | 长期维护的领域 | 编程技术、学习笔记 |
| Resources | 参考资料 | 教程、收藏文章 |
| Archives | 已完成的 | 旧项目笔记 |

### Zettelkasten 原则

1. **原子化**: 每条笔记只包含一个想法
2. **唯一ID**: 使用时间戳或唯一标识符
3. **双向链接**: 通过 `[[链接]]` 关联相关笔记
4. **用自己的话**: 不要复制粘贴，要理解后重述
