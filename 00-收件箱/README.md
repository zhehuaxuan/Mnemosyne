# 00-收件箱 - Inbox

> 所有信息的统一入口，先收集再处理。

## 目录说明

收件箱是所有输入信息的汇聚点，包括：
- 突如其来的灵感
- 快速记录的笔记
- 网页剪藏
- 每日日志

## 子目录

```
00-收件箱/
├── daily/           # 每日日志，按年月组织
├── capture/         # 快速捕获的想法和灵感
└── import/          # 从外部导入的文献、网页等
```

## 使用原则

1. **快速捕获**：任何时刻想到的、看到的，先丢进来
2. **定期清空**：建议每天或每周清理一次
3. **勿在此深耕**：只做快速记录，不做深度思考
4. **持续演进**：定期将有价值的内容迁移到其他目录

## 命名规范

- 每日笔记：`YYYY-MM-DD.md`（如 `2024-07-06.md`）
- 快速捕获：`YYYYMMDD-HHMM-关键词.md`
