# Token Plan 对比

## 第一章：AI Coding SOAT 排名查看渠道

"SOAT" 这个词在 AI 编程领域没有标准对应，但在模型编程能力评测中，有几个**权威基准测试和排行榜**值得关注：

### 1. **SWE-bench** ⭐ 最权威
- **地址**: [https://www.swebench.com/leaderboard](https://www.swebench.com/leaderboard)
- 测试 AI 模型解决真实 GitHub Issue 的能力（从 Python 热门项目中提取）
- 目前 **Claude (Anthropic)** 和 **GPT** 系列经常占据榜首
- 这个是编程能力评测里最公认、最难、也最接近真实场景的基准

### 2. **Aider Polyglot Benchmark**
- **地址**: [https://aider.chat/docs/leaderboards/](https://aider.chat/docs/leaderboards/)
- 测试多语言（Python, JS, Go, Rust 等）的代码编辑能力
- 按语言分组排名，更细粒度

### 3. **BigCodeBench**
- **地址**: [https://bigcode-project.org](https://bigcode-project.org)
- 由 HuggingFace 维护，专注代码生成质量

### 4. **LMArena / LiveBench**
- **地址**: [https://lmarena.ai](https://lmarena.ai)
- 提供交互式多维度评测，包括 Coding 专项

### 5. **OpenCompass**（司南）
- **地址**: [https://opencompass.org.cn/leaderboard](https://opencompass.org.cn/leaderboard)
- 上海人工智能实验室出品，中文友好，综合评测

### 四、笔者实际使用体验 ⭐

> 纸面数据是一回事，实际用起来是另一回事。以下基于笔者过去几个月在 Claude Code 中的真实使用体验，按「**代码质量优先，其次才是价格**」的原则逐家点评。

#### 核心排序逻辑

**代码质量 > 额度够用 > 购买体验 > 价格。**

一个便宜的模型写出来的代码你要花双倍时间 debug，那省下来的钱毫无意义。所以下面的评价，代码能力永远是第一维度。

---

#### MiniMax — 纸面性价比之王，实际体验拉胯 😐

¥119 买 18 亿 tokens，数字上确实无敌。不限购、1M 上下文、月配额无窗口限制——看参数表你会觉得"这不买是人？"但实际用下来：

- **M3 的代码能力远不如 GLM-5.2**：SWE-bench Pro 59.0 vs GLM-5.2 的 62.1，3 分的差距在实际编码中感受巨大。复杂重构、多文件联动修改、深度推理场景下，M3 频繁给出"看起来对但跑不通"的代码，你可能要反复 prompt 3-5 次才能得到一个能用的结果
- **API 稳定性堪忧**：高峰期 5xx 和超时是家常便饭，Claude Code 频繁 retry 非常打断心流
- **1M 上下文虽有但注意力衰减明显**：超长对话超过 50 轮后，模型开始"忘记"前面的约束，质量明显下降

> **一句话**：做简单 CRUD、修小 bug、写脚本——够用。复杂重构、架构设计、多文件协同——它会让你崩溃。¥119 买到的不是"便宜好用"，而是"便宜的代价"。

---

#### 智谱 AI — 代码质量最强，但购买体验是灾难 🔥

GLM-5.2 是**目前国产模型里写代码最靠谱的，没有之一**。SWE-bench Pro 62.1、Code Arena #2，实际使用中复杂任务的一次通过率明显高于其他国产模型。但：

- **你根本买不到**：个人版套餐需要蹲点抢，笔者连续蹲了一周才抢到 Max 档。这不是买服务，是抢春运火车票
- **买到了也用不爽**：5 小时窗口限制 + 高峰期 ×3 消耗。你以为 Max 档有 ~8000 次/周，高峰期等效只有 ~2600 次——Claude Code 重度用户一天就能烧掉一大半，然后接下来 4 小时干瞪眼
- **个人版并发极低**：Claude Code 的并行工具调用经常触发限流，你得手动把并行改串行

> **一句话**：代码质量是国产最强，但"有钱花不出去"的体验让人抓狂。如果你能买到且能接受窗口限制，它是写代码的最优选——但这个"如果"太大了。

---

#### 腾讯云 — "不犯错"的最均衡选择 ✅

腾讯云 Pro（¥299/月，3.2 亿 tokens）的最大特点是**没有明显短板**：

- **模型覆盖面广**：GLM-5.1、DeepSeek-V4、Kimi-K2.6、Hy3-preview 全都有，不用纠结选哪个
- **直接扣 token，计费最透明**：用多少扣多少，不玩 Credits/系数/次数这些花活
- **API 稳定性一流**：腾讯云的基础设施确实靠谱，基本没遇到过高频错误
- **3.2 亿 token 对重度用户只是"勉强够"**：按日均 1500 万算，月底会有点紧张，但不会像智谱那样中途断粮

> **一句话**：如果你不想折腾、不想抢购、不想研究各种计费陷阱——腾讯云是最安全的选择。它不会给你惊喜，但也不会给你惊吓。

> ⚠️ **注意**：腾讯云 2026.7.20 起改为积分制，届时的实际性价比需要重新评估。

---

#### 字节方舟 — 促销价是糖衣炮弹 💣

Pro 促销价 ¥49.9 看起来很香，模型覆盖也最全（DSV4、MiniMax-M3、GLM-5.2 全有）。但**千万别被价格迷惑**：

- **高阶模型 ×5 消耗是致命伤**：用 GLM-5.2 或 MiniMax-M3 时，一次请求烧 5 次额度。Pro 档每 5 小时只有 6,000 次请求，等效仅 1,200 次/5h——重度用户小半天就耗尽，然后进入漫长的冷却期
- **促销价 ¥49.9 到 2026.8.7 结束**，正价 ¥200。正价下这个性价比就彻底崩了
- **唯一合算的用法**：只用豆包自研模型（Doubao-Seed-2.0，1× 消耗），促销价下确实便宜。但豆包的代码能力在国产里只能算中游偏上

> **一句话**：¥49.9 买来体验一下可以，正经写代码别跟自己过不去。高阶模型的 ×5 折损让它的"模型最全"变成了"模型最贵"。

---

#### Kimi — 额度不透明，让人不信任 🤔

Kimi K2.7 Code 的长文档分析能力确实强，代码能力也和 MiniMax-M3 同级。但：

- **不公布 token 绝对量**，只给"系数"——你根本不知道买了多少。这种不透明本身就让人不放心
- **高频 ×3 消耗**：Claude Code 重度使用一定会触发
- **代码能力不如 GLM-5.2**，和 MiniMax-M3 属于同一梯队

> **一句话**：更适合做长文档分析和研究，不太适合作为 Claude Code 的主力编码模型。

---

#### 阿里百炼 — 企业专供，个人勿入 🏢

- **Credits 消耗规则完全不透明**：你不知道一次请求扣多少，完全是黑盒
