## 目标

让 AI 能够准确理解、检索和利用个人知识库中的信息，形成真正的「第二大脑」。

## 为什么需要 AI 友好的知识库

### 传统笔记 vs AI 时代的笔记

| 传统笔记 | AI 友好的知识库 |
|---------|---------------|
| 人类可读即可 | 需要结构化让 AI 理解 |
| 散落的信息孤岛 | 连贯的知识网络 |
| 难以被复用 | 可被 AI 推理和组合 |

### 核心问题

AI 无法理解：
- 模糊的上下文
- 隐含的关联
- 无结构的长文

## PARA + Zettelkasten 最佳实践

### PARA 分类原则

```
00-工作流/          ← 当前正在进行的流程
├── 1-收件箱/       ← 临时入口，AI 加工后分流
├── 2-进行中/       ← 正在执行的任务
└── 3-模板库/       ← 可复用的模板

10-项目/           ← 有明确目标 & 截止日期
20-领域/           ← 长期维护的专业领域
30-资源/           ← 参考资料（无需深度加工）
40-归档/           ← 完成的项目、已消化的资源
```

### Zettelkasten 原子化原则

**每条笔记只包含一个核心想法：**

```
✅ 好：单一想法
"Claude 3.5 Sonnet 在 SWE-bench 上达到 49% 准确率"

❌ 差：多个想法混合
"Claude 3.5 很强，在编程测试上表现好，GPT-4 也不错..."
```

**好处：**
1. 便于精准链接
2. AI 能准确匹配和组合
3. 避免信息冗余

## 让 AI 读懂笔记的技巧

### 1. 善用 YAML Frontmatter

```yaml
---
title: SWE-bench 评测结果
date: 2026-07-09
tags: [AI评测, 编程能力, Claude, GPT]
source: https://www.swebench.com/leaderboard
related:
  - "[[Token Plan对比]]"  # 相关笔记
type: 评测数据
---
```

### 2. 使用双向链接

```
在笔记中引用：
"根据 [[SWE-bench]] 评测，Claude 在编程任务上表现最佳"

AI 可以追踪：
- 当前笔记引用了哪些笔记
- 哪些笔记引用了当前笔记
```

### 3. 统一标签系统

**推荐结构：**
```
#领域/子领域    #项目/项目名    #状态/待处理    #类型/概念
#AI/LLM        #项目/mnemosyne #状态/wip       #类型/教程
```

**避免：**
- 过多标签（>10个）
- 模糊标签（如 #重要、#好）
- 标签嵌套过深

### 4. 卡片笔记命名规范

```
格式：[主题]-[唯一标识]

✅ good-20260709          ← 时间戳唯一 ID
✅ ai-coding-benchmarks    ← 描述性命名

❌ 笔记1                   ← 无意义
❌ 我的想法                 ← 太模糊
```

### 5. 使用 MOC (Map of Content)

为每个领域创建索引笔记：

```markdown
# 20-领域/AI/MOC - AI 学习索引

## 核心概念
- [[AI基础概念清单]]
- [[LLM技术原理]]

## 评测与排行
- [[Token Plan对比]]  ← 指向具体笔记

## 项目实践
- [[AI项目复盘]]

## 待整理
- [[AI相关待消化内容]]
```

```
┌─────────────┐
│  信息输入    │  收件箱
└──────┬──────┘
       │
       ▼
┌─────────────┐

       ▼

       ▼

       │
       ▼

```

## 实践检查清单

### 新笔记创建时
- [ ] 有清晰的标题
- [ ] 包含 frontmatter 元数据
- [ ] 是原子化的（单一想法）
- [ ] 链接到相关笔记
- [ ] 添加了相关标签

### 知识库维护时
- [ ] 定期检查孤立笔记（未被引用的）
- [ ] 更新过时的信息
- [ ] 合并重复内容
- [ ] 清理无用标签

## 总结

**让 AI 读懂知识库的关键：**

1. **结构化** - 使用 PARA 分类 + MOC 索引
2. **原子化** - 每条笔记一个想法
3. **链接化** - 双向链接构建知识网络
4. **元数据化** - frontmatter + 标签
5. **标准化** - 命名规范和模板

> 好的知识库不是信息的堆砌，而是让 AI 能够推理、组合、创新知识的有机系统。
