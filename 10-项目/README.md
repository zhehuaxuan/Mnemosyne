# 10-项目 - Projects

> 当前正在进行的项目，每个项目一个子目录。

## 目录说明

存放所有**有明确交付物和截止日期**的项目，包括工作项目和 side project。

## 目录结构

```
10-项目/
├── <项目名>/
│   ├── index.md           # 项目索引/概览
│   ├── docs/              # 项目文档
│   │   ├── requirements.md
│   │   └── architecture.md
│   ├── meeting/           # 会议记录
│   ├── decisions/         # 架构决策记录 (ADR)
│   └── notes/             # 项目相关笔记
└── ...
```

## 使用原则

1. **一个项目一个文件夹**：保持项目内聚性
2. **index.md 是入口**：放项目简介、目标、关键链接
3. **ADR 记录决策**：重要技术决策要记录上下文和理由
4. **项目结束后归档**：完成或搁置后移至 40-归档

## 适用内容

- 工作项目 / 工作任务
- Side Project / 个人项目
- 开源贡献
- 技术调研
