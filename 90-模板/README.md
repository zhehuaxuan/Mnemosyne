# 90-模板 - Templates

> 可复用的笔记模板，提高记录效率。

## 目录说明

存放各类笔记的标准模板，方便快速创建新笔记。

## 模板列表

### 每日笔记模板

```markdown
# {{date}}

## 今日完成
-

## 今日学习
- 新概念：
- 重要发现：

## 明日计划
-

## 灵感与想法
-

## 引用 / 参考
-
```

### 项目模板

```markdown
# {{project_name}}

## 概述
-

## 目标
-

## 技术栈
-

## 进度
- [ ]

## 关键链接
-

## 决策记录
| 日期 | 决策 | 理由 |
|------|------|------|
| | | |
```

### 读书笔记模板

```markdown
# {{book_name}}

## 书籍信息
- 作者：
- 类型：
- 阅读状态：

## 核心观点
-

## 关键收获
-

## 实践应用
-

## 摘录
> {{quote}}

## 相关笔记
- [[]]
```

### ADR 模板 (架构决策记录)

```markdown
# ADR-{{number}}: {{title}}

## 状态
{{proposed|accepted|deprecated}}

## 背景
-

## 决策
-

## 后果
### 正面
-
### 负面
-
```

## 使用方法

使用 Obsidian、Templater 插件或 Logseq 的模板功能引用这些模板。
