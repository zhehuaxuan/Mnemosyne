# 50-笔记 - Zettelkasten 原子笔记

> 原子化的永久笔记，通过链接形成知识网络。

## 目录说明

采用 Zettelkasten（卡片盒笔记法）的核心理念，每条笔记只包含**一个想法**，通过双向链接与其他笔记形成网络。

## 目录结构

```
50-笔记/
├── permanent/              # 永久笔记（核心）
│   ├── concepts/           # 概念定义
│   ├── methods/            # 方法论
│   └── patterns/           # 模式总结
├── literature/             # 文献笔记
│   └── books/
├── index/                  # MOC (Maps of Content) 主题索引
└── fleeting/               # 临时笔记（待整理）
```

## 四层笔记流程

```
1. 闪念笔记：快速捕获的想法，还未整理
         ↓
2. 文献笔记：阅读后的简短总结，用自己的话重述
         ↓
3. 永久笔记：经过深思熟虑的原子化笔记，包含自己的想法
         ↓
4. 索引笔记：作为入口点，链接到相关主题
```

## 使用原则

1. **原子性**：每条笔记只包含一个独立想法
2. **自包含**：不依赖上下文也能理解
3. **链接优先**：用 `[[双向链接]]` 而非文件夹层级
4. **自己的想法**：不是摘抄，而是用自己话重述
5. **MOC 索引**：每个主题创建索引笔记作为入口

## 命名规范

- 概念：`概念名.md`（如 `SOLID原则.md`）
- 方法：`方法名.md`（如 `TDD测试驱动开发.md`）
- 模式：`模式名.md`（如 `CQRS模式.md`）
