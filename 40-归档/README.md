# 40-归档 - Archives

> 不再活跃但可能未来有用的内容。

## 目录说明

归档不再需要频繁访问但仍想保留的资料。

## 目录结构

```
40-归档/
├── old-projects/           # 已完成 / 废弃的项目
├── deprecated-tech/        # 已过时的技术文档
├── reference/              # 历史参考资料
└── temp/                   # 临时归档（待清理）
```

## 使用原则

1. **定期归档**：活跃项目完成后及时移入
2. **可检索**：即使归档也要能通过搜索找到
3. **不过度留恋**：没有长期价值的内容可直接删除
4. **如果旧项目重新激活**：移回 10-项目
