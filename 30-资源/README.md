# 30-资源 - Resources

> 感兴趣但暂不行动的参考资料，可视为「精神图书馆」。

## 目录说明

存放阅读、学习、收藏的资料，包括书籍、文章、课程等。

## 目录结构

```
30-资源/
├── books/                   # 读书笔记
│   ├── read/               # 已读完
│   ├── reading/            # 正在读
│   └── to-read/            # 待读清单
├── articles/                # 保存的技术文章
├── courses/                 # 学习课程
│   ├── completed/          # 已完成
│   └── in-progress/        # 进行中
├── videos/                  # 技术视频 / 演讲
├── tools/                   # 工具收藏
└── newsletter/             # 订阅的 newsletter
```

## 使用原则

1. **读完必有笔记**：读过的书写读书笔记
2. **来源标注**：记录原文链接，方便溯源
3. **与领域区分**：资源是输入，20-领域是内化的知识
4. **定期清理**：不再有用的资源及时归档或删除

## 适用内容

- 书籍读后感 / 摘要
- 有价值的文章链接
- 在线课程笔记
- 技术大会演讲资料
- 工具推荐与配置
