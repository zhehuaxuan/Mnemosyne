# Mnemosyne - 个人知识库

> 源于希腊记忆女神 Mnemosyne，构建你的第二大脑。

## 知识库概览

本知识库基于 **PARA + Zettelkasten** 方法论设计，采用行动导向的目录结构。

## 目录结构

```
Mnemosyne/
├── 00-收件箱/      # 收件箱 - 所有输入的入口
├── 10-项目/        # 项目 - 有明确交付物和截止日期
├── 20-领域/        # 领域 - 长期关注的技术领域
├── 30-资源/        # 资源 - 读书、学习、参考资料
├── 40-归档/        # 归档 - 不再活跃但保留的内容
├── 50-笔记/        # Zettelkasten 原子笔记
└── 90-模板/        # 模板库
```

## 设计原则

1. **行动导向**：按用途（项目/领域/资源）组织，而非按主题
2. **原子化 + 链接**：笔记小而专注，通过 `[[双链]]` 发现关系
3. **收件箱清零**：每天/每周清理 inbox
4. **渐进式提炼**：从快速捕获到永久笔记的演进
5. **可发现性优先**：良好的命名和链接比深层目录重要

```
	看到/想到什么 → 丢进 00-Inbox（收件箱）  
	↓ 每天/每周整理  
	有用的内容 → 移到 20-Areas 或 50-Notes  
	项目做完 → 移到 40-Archives
```

## 核心方法论

### PARA 体系
- **项目**: 当前活跃项目
- **领域**: 长期责任领域
- **资源**: 感兴趣的参考资料
- **归档**: 历史归档

### Zettelkasten
- 原子化笔记
- 双向链接
- 自生长知识网络

## 快速开始

1. **每日记录**：在 `00-收件箱/daily/` 创建每日笔记
2. **快速捕获**：任何灵感丢入 `00-收件箱/capture/`
3. **项目笔记**：在 `10-项目/` 建立项目文件夹
4. **技术积累**：在 `20-领域/` 沉淀领域知识
5. **读书笔记**：在 `30-资源/books/` 记录读后感
6. **原子笔记**：在 `50-笔记/` 创建链接的知识网络
