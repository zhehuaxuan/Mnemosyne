# 20-领域 - Areas

> 长期关注的技术领域，无截止日期，持续学习积累。

## 目录说明

存放对某一技术领域的系统化知识积累，是知识库的核心资产。

## 目录结构

```
20-领域/
├── backend/                 # 后端技术
│   ├── database/           # 数据库
│   ├── api-design/         # API 设计
│   ├── architecture/       # 架构模式
│   └── messaging/          # 消息队列
├── frontend/               # 前端技术
│   ├── react/
│   ├── vue/
│   └── css/
├── devops/                 # DevOps
│   ├── docker/
│   ├── kubernetes/
│   └── ci-cd/
├── security/               # 安全
├── ml-ai/                  # 机器学习与 AI
├── investment/             # 投资
└── management/             # 技术管理
```

## 使用原则

1. **按技术栈/职能组织**：而非按具体技术名称
2. **持续更新**：随学习和实践不断补充
3. **原子化**：每条笔记一个主题，通过链接关联
4. **重链接、轻层级**：优先用 `[[双链]]` 而非深层目录

## 适用内容

- 某技术栈的学习笔记
- 最佳实践总结
- 踩坑记录与解决方案
- 架构设计思考
- 投资知识积累
